# CV page

Одностраничная визитка Java-инженера, работающего по договору. Живёт отдельно от
`robotics-consulting`: тот сайт продаёт автоматизацию владельцам малого бизнеса,
а эта страница отвечает на другой вопрос — кто такой исполнитель и что он уже
построил. Ссылка из объявлений на ss.com ведёт сюда напрямую.

Статическая страница, без сборки. Механика та же, что на основном сайте:
`data-i18n` в HTML + словари в `locales/*.json`.

## Структура

```
index.html        разметка
style.css         стили
script.js         логика (i18n + тема)
locales/lv.json   латышский (язык по умолчанию)
locales/ru.json   русский
locales/en.json   английский
```

## Что нужно заполнить перед публикацией

Все незаполненные места помечены префиксом `TODO:` в словарях:

```bash
grep -n "TODO:" locales/*.json
```

Правится только JSON, HTML трогать не нужно. Ключи во всех трёх файлах
одинаковые — если добавляешь ключ, добавь во все три.

Отдельно, в `script.js`, в объекте `CONTACT`: телефон в двух видах —
как показывать и как ссылку `tel:`.

Проверить, что ничего не забыто и словари согласованы:

```bash
python3 check.py
```

## Локальный запуск

Из-за `fetch` для словарей файл нельзя открывать как `file://` — нужен сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

Репозиторий: https://github.com/arthur-staseljun/cv (ветка `master`).

1. Settings → Pages → Source: `Deploy from a branch`, ветка `master`, папка `/ (root)`.
2. Через минуту страница открывается на https://arthur-staseljun.github.io/cv/

**Не включай Pages, пока `check.py` не даст код 0** — иначе в интернет уедут
незаполненные места вроде «TODO: ставка».

Workflow с Actions здесь не нужен: в `robotics-consulting` он есть, потому что там
так исторически сложилось, но для статики хватает деплоя из ветки.

Если позже захочешь свой домен — положи файл `CNAME` с одним именем внутри.
Домены `robotics-consulting` и `cv` друг другу не мешают: GitHub Pages даёт по сайту
на репозиторий, ограничение «один index» действует на папку, а не на аккаунт.

## Мелочи, которые уже сделаны

- тема тёмная по-умолчанию и светлая, переключатель запоминается в `localStorage`;
- язык по-умолчанию — латышский, переключатель запоминается в `localStorage`;
- `@media print` — страница нормально печатается и сохраняется в PDF
  (Cmd+P → Save as PDF), чтобы можно было приложить файлом к отклику.
